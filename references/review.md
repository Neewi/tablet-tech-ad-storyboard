# 双重审核与返修

静态图是否准确、动态规划是否成立分开检查。文件校验不能替代实际看图；关键帧不能证明最终视频已经正确执行。不得把未查看的图片写成已审通过。

## 生成前

- 输入模式、参数及套装清单明确；无参数不追问全部规格，有参数未齐不猜。
- 查看当前型号原图及实际配件，确定可展示部位。摄像头的装饰环不自动当成多个真实镜头，接口开孔不自动推断功能。
- 本次 40 秒有完整内容分配、多处实体概念联系、强动势与清晰到达；没有 10 秒只做一个孤立概念。
- 多个创意方向在概念和路径上有区别；所选四段共享风格，非只换蓝紫色背景。

## 每图逐格看

| 项目 | 实际核验 |
|---|---|
| 机身 | 轮廓、长宽、厚度观感、边框、圆角、正背颜色、装饰带、前摄和后摄布局是否与本型号原图一致 |
| 可见细节 | 开孔、按钮、摄像头/灯位、轮廓是否随角度变化消失、复制或跳位；不支持的隐藏细节是否被发明 |
| 配件 | 键盘仍是原款分离式；鼠标、银笔、壳、线、充电头外观、数量与实际清单一致 |
| 保护壳 | 公共原图黑色纹理、平铺外形、两横折线三面板；无依据的支架/内侧/相机孔不能接受 |
| 连接 | 同一根线、同一接口、合理端头方向与支撑；不靠漂浮/遮挡掩盖明显错误 |
| 人物 | 头眼确实朝向屏幕显示面，视线能落入屏幕；手掌、手指、键盘和支撑合理，不看背板 |
| 屏幕 | 内容在实际显示边界内；概念进出有可解释的广告表达，不暗示真实全息/投屏功能 |
| 文字 | 有参数逐字核准、单位与物理/扩展含义正确且能读；无参数所有表面和 UI 都无旧配置 |
| 构图 | 商品足够大可识别；人物或背景电视不抢主体；单格具备视频画面构图而非海报拼贴 |

出现物品形状偏差，就回到原图修正受影响的格。不能用“整体效果好”豁免保护壳、机身和人物错误。

## 动势与概念检查

暂时收起视频提示词，单看已经生成的宫格。为每个主要联动指出三个画面状态对应的格号：能认出商品、能看出概念怎样接触或延续商品、能看出最终结果。状态可以跨格或共享一格。例如，用同一张可辨认的图像跨过屏幕边缘，在下一格完整落入显示区。若只能指出一格抽象效果和一格商品，中间关系还需要靠文字解释，修订中间关键帧后再交付。

对照时间轴与宫格，指出每处动作的起点、方向、速度变化、终点和对应格。多处不同主题的概念事件都能解释与平板的联系，不能只有发光线条或孤立动画。

确认有宏微尺度变化、强前景视差/转向等足以形成冲击的设计，并给产品看清的落点。相邻格只变光色、物体与相机完全没动，不能声称大幅运动已表达。概念内容始终在推进，但不要求刚性商品和人物每秒都做大幅翻转。

检查“能生成”的动作组织：不要同一瞬间要求旋转机身、插入线缆、重排全套和可读多行文字。复杂运动保留主动作，使用合理切镜、遮挡或已连接状态解决歧义。简化执行方式不能删除视觉冲击本身。

## 图文与整片

- 逐格编号、参考顺序、时段、姿态、物品、文字和运动能对上；没有词说向内汇聚而图向外散开的冲突。
- 各段文字时长总计 10 秒，无重叠矛盾；四段共 40 秒，内容分配完整。秒级时间是设计目标，不声称逐帧保证。
- 生图前按每段本地 0–10 秒选出一组建议保留区间，合计约 30–35 秒，其中使用场景约 9–10 秒。顺读裁后时间轴，确认主要联动的中间状态、必要参数的可读窗口、用途与全套揭示都保住，段间方向或切点能接上。删减会破坏其中之一时，先改镜头时间分配。核图后将区间建议同步到对应表，注明实际切点以 Gemini 成片为准。
- 带参数时逐条指定唯一的画面位置。对照出现、可读、退出三个状态，核查同一句话是否同时出现在芯片、屏幕和画外，以及退出后是否留下碎字。
- 四段同一型号、同一配件版本，颜色与空间语言协调；没有复制其他型号摄像头或把通用合成图机身带入。
- 充电头选择、参数开关贯穿全片；收尾准确全套、配件布局固定；不必用完所有原图。
- 正常全屏首帧明确，格线/编号不成为视频片头。独立生成边界便于裁剪拼接，不要求复杂后期。
- 视频提示词内只有执行内容，不含本审核流程、技能制作要求或空泛风格命令。

## 返修与真实状态

每张初次生成后最多自动修两轮，针对具体缺陷修正并重新核验；局部修订后也检查其他区域是否退化。涉及运动路线或风格根源时先改规划，再改图和词。用户给定其他额度/返修范围时以用户为准。

超过范围仍有缺陷，停下该失败片段并明确问题，已通过成果保留。不要无限重试、静默发布失败图，或通过只写“已约束”掩盖未修正画面。需要用户决定时，给具体问题和影响。

最终标明是参考图与提示词已完成；没有生成/查看的视频不可宣称通过。后续用户另行给视频审阅时，重点查首帧宫格泄露、持续商品身份、人物视线、配件与线缆、参数文字，以及计划的快慢变化和概念联系是否实际发生。
